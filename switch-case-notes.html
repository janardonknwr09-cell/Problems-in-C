Switch Case in C

Detailed beginner notes with examples and practice

1. What is a switch statement?

A switch statement selects one block of code from several choices. It compares one expression with exact constant values called case labels.

It is useful when a program has a menu or a fixed list of choices, such as month numbers, menu options, or calculator operations.

2. General syntax

switch (expression)
{
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    default:
        statements;
}
  • expression is the value being tested.
  • case gives one possible value.
  • The colon : is required after every case value.
  • break exits the switch.
  • default runs if no case matches.

3. Step-by-step example

#include <stdio.h>

int main()
{
    int number = 2;

    switch (number)
    {
        case 1:
            printf("One");
            break;

        case 2:
            printf("Two");
            break;

        default:
            printf("Invalid number");
    }

    return 0;
}

First, number contains 2. The switch checks its cases and finds case 2. It prints Two, then break exits the switch.

4. Understanding break

Without break, C continues executing the next statements, even when the next case does not match. This is called fall-through.

int number = 1;

switch (number)
{
    case 1:
        printf("One ");

    case 2:
        printf("Two");
}

Output: One Two. Usually this is not wanted, so place break at the end of each case.

5. Intentional fall-through

Fall-through can be useful when several choices need the same result:

switch (month)
{
    case 4:
    case 6:
    case 9:
    case 11:
        printf("30 days");
        break;
}

If month is 4, 6, 9, or 11, all choices reach the same print statement.

6. The default case

default is similar to the final else in an if-else chain. It handles invalid or unexpected input.

switch (choice)
{
    case 1:
        printf("You selected option 1");
        break;

    default:
        printf("Invalid choice");
}

7. Complete month program

#include <stdio.h>

int main()
{
    int month;

    printf("Enter month number (1-12): ");
    scanf("%d", &month);

    switch (month)
    {
        case 4:
        case 6:
        case 9:
        case 11:
            printf("Number of days: 30");
            break;

        case 1:
        case 3:
        case 5:
        case 7:
        case 8:
        case 10:
        case 12:
            printf("Number of days: 31");
            break;

        case 2:
            printf("Number of days: 28 or 29");
            break;

        default:
            printf("Invalid month number");
    }

    return 0;
}

For input 7, the program selects case 7 and prints Number of days: 31.

8. switch versus if-else

  • Use switch for one expression and exact choices: 1, 2, 3, or 4.
  • Use if-else for ranges: marks >= 90.
  • Use if-else for multiple conditions involving different variables.
  • A switch does not directly compare strings such as "January".

9. Important rules and common mistakes

  • Do not write case x > 5:; a case needs a constant value.
  • Do not repeat the same case value.
  • Remember the colon after the case value.
  • Remember break unless fall-through is intentional.
  • Use &month in scanf because month is an integer variable.
  • With this program, enter a number such as 7, not a name such as July.
